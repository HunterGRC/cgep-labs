# Compliant S3 Primitive (Lab 2.3)

This module enforces SC-28, AU-3, AU-6, CM-6, AC-3 on a single S3 bucket. It enforces server-side KMS encryption at rest (SC-28), object versioning and baseline configuration settings (CM-6), mandatory audit and governance resource tagging (AU-3, AU-6), and strict public access blocking across all ACLs and bucket policies (AC-3).
